留白庭院 / 池畔手记 · 手机适配 · 自由地形沙盒版

核心：画出池塘与小路 → 画圈创造物件 → 自由摆放 → 动物察觉环境 → 观察后继续调整。
沿用画风第二版的镜头、动物轮廓、树冠叠色、草地纸纹和水面色洗。
动物与造景都使用同一套“停顿—局部显形—稳定”的显形时序。

手机版：
- 手机网页支持竖屏与横屏。竖屏默认近景，“全景 / 近景”切换；视野外的角落可用双指移动到。
- 单指在空地画圈，点选物件后拖动摆放；双指拖动平移、捏合缩放。第二根手指加入会取消尚未提交的笔迹或拖放，直到全部手指离开才重新允许绘制。
- 小动物的触控选择范围扩至至少 44 像素；按钮至少 44×44。物件操作竖屏在底部，横屏在右侧，可点 × 取消选择。
- 工具栏和镜头会给手机安全区、底部手势条与浏览器高度变化留出空间；切换方向会安全取消未完成手势。
- 手机渲染像素比上限 1.5，以 30 帧为目标节奏；切到后台保存并暂停画面，返回后继续。
- 手机与本机在同一局域网时可打开 http://电脑局域网IP:8765/ 试玩（当前地址，IP 变化后需更新）。本机开发预览仍为 http://localhost:8765/。
- 这是手机网页适配，当前已完成浏览器尺寸与触控状态逻辑验证，尚未连接 iPhone / Android 真机测试流畅度。

地形画笔：
- 下方“地形”分类选择“水面”或“小路”，拖动绘制，用“笔宽”调节粗细。
- 水面可涂画、补画；围成闭合轮廓会填满内部，开放笔迹则形成水湾或水道。
- 选择“擦去”即可缩小、切开或改形；在水中擦去一块可留下小岛，能继续在岛上放物件。
- 小路沿草地铺开，多笔自然接续；可擦去局部再改走向。水面与小路分别编辑，小路不会覆盖水面。
- 新的水色、小路、岸草会在短暂停顿后柔和出现；撤回和重做也使用同样的过渡。
- 地形编辑保留最外沿的一圈草地，给动物留出安全的岸边。

怎么玩：
- 下方“小生命”画笔：青蛙、小鸭、小兔。
- “造景”画笔：荷叶、树、花丛、石头。在空地画闭合圈生成，圈的大小影响物件大小。
- 树、花、石头放在岸上，荷叶放在水面；按住已有物件或动物即可拖动。
- 摆放时地面圈提示有效位置，松开后保留最后一个有效位置。点选树、花或石头可转向；所有对象可近看或移走。
- 点选荷叶可开花、漂动、请青蛙；动物保留原来的小动作。
- “撤回 / 重做”支持本次打开期间的水面/小路绘制与擦除、生成、摆放、转向、开花与移走；只回退对应物件，不回退动物的整个活动过程。
- 物件和自绘地形自动保存在当前浏览器此地址下，刷新会恢复；旧版庭院会保留物件并迁移。更换浏览器或地址不会同步。
- 右键 / 中键 / 空格拖动平移，滚轮缩放，双击近看，“全景”返回；触屏支持双指缩放和平移。

环境关系：
- 地形变化不会删除或自动搬走已有物件；失去水面的荷叶会变淡，补画水面或拖回水中后恢复。
- 物件摆放与动物寻路读取同一份新地形；小兔脚下被补画水面时，会慢慢回到岸上。
- 青蛙会寻找荷叶和石头歇脚，也会到花边等小虫；小荷叶只接待一只主动前来的青蛙。
- 小兔会去树旁休息，也会凑近花丛闻一闻；寻路时绕开池塘、树干和石头。
- 小鸭会慢慢游逛，到荷叶旁觅食，也会留意岸上的花丛。
- 注意环境、移动、停留都有间隔和偏好；动物不会在摆好物件后立刻全体聚集。
- 移动或移走目标后，动物会重新考虑目的地，自己走过去；落点占到动物的位置时，它可以慢慢走出。

键盘辅助：
- 聚焦画布，未选中时方向键移动落点，回车生成物件；使用地形画笔时回车按当前笔宽落一笔。Esc 取消选择。
- 选中时方向键移动对象，Shift + 方向键较大步移动，R 转向。
- Ctrl / Command + Z 撤回，Shift + Ctrl / Command + Z 重做，0 返回全景。

运行：本目录执行 npm start，打开 http://localhost:8765。
浏览器运行依赖已附在 vendor/，运行游戏不需要先安装依赖；执行测试前运行 npm ci。无需 API Key。

验证：npm test 覆盖手势识别、几何与轮廓、显形时序、绘画材质与显形组合、岸线判定、摆放约束、水陆寻路、环境偏好、抵达与停留、目标移动/删除后的重新选择、占位脱困、撤销重做和存档校验。terrain.test.js 另覆盖自由轮廓填充、接续水道、小岛、路面接续与擦除、水陆优先级、地形撤回重做、旧存档迁移、地形变化后的寻路与回岸、连续绘制的柔和过渡。
实机检查已验证生成、拖动树、撤回重做、青蛙主动到新荷叶上歇脚；地形版另验证拖出相连水湾、分笔接续小路、擦出小岛并种树、局部擦路后撤回，以及刷新恢复自绘地形和物件。
sandbox-environment-response.png 为环境反应实机画面；freeform-garden-v1.png 为自绘水湾、小岛与接续小路的实机画面。造景生成的验证包含键盘辅助触发，水面和小路的验证使用实际指针拖动。

本版为可编辑水面与小路的小型庭院沙盒。地形用平面笔刷修改，不包含高低起伏或流体模拟；导航仍为轻量规则。天气、繁殖和声音尚未加入。

手机验证：mobile-controls.test.js 覆盖横竖屏取景、44px 选择范围、拖放意图、双指接管、抬起一指后继续移动和三指中断。浏览器另检查 320×568、390×844、844×390 及桌面 1280×772 的布局、按钮尺寸、物件菜单、全景切换、横屏画路与撤回。mobile-garden-portrait.png 和 mobile-garden-landscape.png 为浏览器尺寸验证截图。
